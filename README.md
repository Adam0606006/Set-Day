# 📊 Трекер настроения и продуктивности

Telegram-бот для ежедневной записи настроения, часов работы и сна. Автоматически считает статистику, строит графики и анализирует влияние режима на самочувствие.

## 📁 Структура проекта

```
📦 main/
├── 📂 PyFiles/
│   ├── bot.py          # Точка входа, запуск polling
│   ├── config.py       # Токен бота
│   ├── db.py           # Подключение и запросы к SQLite
│   ├── handles.py      # Обработчики команд и шагов
│   ├── keyboards.py    # Генерация Reply-кнопок
│   └── stats_logic.py  # Расчёт статистики, инсайтов и графиков
├── 📂 DbFiles/
│   ├── users.sql       # Схема таблицы пользователей
│   └── records.sql     # Схема таблицы записей
├── .gitignore          # Исключение кэша, БД и секретов
├── requirements.txt    # Список зависимостей
└── README.md           # Документация
```

## 🚀 Запуск

**1. Установите зависимости:**

```bash
pip install -r requirements.txt
```

**2. Настройте токен:**

Откройте `PyFiles/config.py` и вставьте свой токен от @BotFather:

```python
TOKEN = "ВАШ_ТОКЕН_ЗДЕСЬ"
```

**3. Запустите бота:**

```bash
python PyFiles/bot.py
```

**4. Начните работу:**

Напишите боту в Telegram команду `/start`

## 🎮 Кнопки меню

| Кнопка | Описание |
|--------|----------|
| **➕ Записать день** | Пошаговый ввод данных: настроение → работа → сон → комментарий |
| **📊 Статистика** | Просмотр статистики за неделю/месяц, инсайты и график |
| **📜 История** | Показать последние 5 записей |
| **🧹 Очистить данные** | Удалить всю историю (требуется подтверждение) |
| **👩‍💻 Помощь** | Показать список команд |
| **Назад** | Вернуться в главное меню |

## 💡 Возможности

- ✅ **Ежедневный учёт** — записывайте настроение (1–5), часы работы и сна
- ✅ **Защита от дублей** — нельзя добавить две записи за один день
- ✅ **Аналитика** — средние значения за неделю и месяц
- ✅ **Инсайты** — бот подскажет, как сон и работа влияют на настроение
- ✅ **Визуализация** — график динамики по трём параметрам
- ✅ **Приватность** — все данные хранятся локально в SQLite

## ⚙️ Технические детали

- **База данных:** SQLite (`table.db`), создаётся автоматически
- **Графики:** matplotlib (временные файлы удаляются после отправки)
- **Python:** версия 3.7 и выше
- **Зависимости:** 
  - `pyTelegramBotAPI`
  - `matplotlib`

## ⚠️ Важно

- 🔒 **Не публикуйте** файл `config.py` с токеном в публичный доступ
- 🗑️ **Добавьте** в `.gitignore`: `config.py`, `table.db`, `__pycache__/`, `*.png`
- 💾 **Резервное копирование** `table.db` сохранит всю историю данных
